## Pattern

Alle Skripts folgen einer einheitlichen **Vier-Säulen-Struktur**:

1. **Prüfungsfrage** (Schulrätin-Kolb-Stil, multidimensional)
2. **Kernnormen** (norm-hierarchisch geordnet: Bundesrecht / BV / BayEUG / VO / KMBek)
3. **Antwort-Choreographie** in 6 Schritten (Sachverhalt → Quellen-Verortung → Grundsatz → Subsumtion 1 → Subsumtion 2 → Pädagogische Stellungnahme + Handlungspfad)
4. **Nachfragen + Falle-Atlas + Top-N-Pflichtwissen + Cross-Refs + Praxisanker + Quellen**

## Verlinkung
